隱私權政策

適用產品：PageZhi｜頁織 Chrome 擴充功能（版本 2.2.0）
最後更新：2026 年 11 月 23 日

1. 適用範圍

本政策說明 PageZhi｜頁織（以下簡稱「本擴充功能」）如何在提供網頁截圖、圖片編輯、PDF 匯入及匯出功能時，存取、使用和保存資料。

2. 處理的資料與使用目的

當你主動使用截圖功能，本擴充功能會處理你選擇的網頁畫面或區域，內容可能包含文字、圖片、個人資料或敏感資訊。當你主動匯入 PDF 或圖片，或使用標註、裁切、馬賽克、複製、下載等功能時，本擴充功能亦會處理相關內容。

這些資料僅用於執行你要求的畫面擷取、內容編輯、PDF 處理與輸出操作。本擴充功能不以追蹤瀏覽歷史、建立使用者輪廓或廣告定向為目的。

3. 瀏覽器權限用途

  • activeTab：在你主動啟用擷取功能時，暫時存取使用中的分頁以擷取畫面。
  • scripting：在目前分頁執行本擴充功能隨套件提供的程式，進行畫面尺寸量測、捲動擷取與區域框選。
  • clipboardWrite：依你的操作，將擷取或編輯的圖片複製到系統剪貼簿。
  • file:///*：在 Chrome 允許本擴充功能存取檔案網址的情況下，支援讀取使用者開啟的本機 PDF。

4. 本機儲存及保存期限

為了將完整網頁的分段截圖重組並開啟編輯器，本擴充功能可能把截圖工作資料與圖片分塊保存在瀏覽器本機的 IndexedDB（名為 captures 的資料庫）。

版本 2.2.0 未提供已確認的自動到期刪除機制。暫存資料可能持續保留於瀏覽器的擴充功能儲存空間，直到你清除相關擴充功能資料、移除本擴充功能，或未來版本提供其他清理方式。關閉編輯器不代表資料一定已刪除。

5. 網路請求、第三方與分享

依目前 2.2.0 版本的功能程式，本擴充功能沒有將截圖或 PDF 上傳至開發者管理伺服器的功能，也未整合第三方廣告追蹤或使用分析服務。

當你要求從目前開啟的 HTTP／HTTPS PDF 網址匯入文件時，瀏覽器可能向該 PDF 來源網站發送讀取請求，並依瀏覽器規則附帶適用的 Cookie 或登入憑證。該來源網站對請求及資料的處理，依其自身政策而定。

若你主動將圖片複製到剪貼簿、下載或分享至其他應用程式，資料將依你的操作進入你選擇的目的地；這些目的地的資料處理不由 PageZhi 控制。

6. 資料使用限制

本擴充功能不出售使用者資料，不為與本擴充功能明示用途無關的目的轉移使用者資料，也不使用使用者資料進行信用評等或貸款決策。

本擴充功能對使用者資料的使用遵循 Chrome Web Store User Data Policy（含 Limited Use 要求）。

7. 你的控制與資料刪除

你可以選擇是否啟動擷取、選取範圍、匯入文件、複製或下載。若想刪除本機暫存資料，可透過 Chrome 的擴充功能儲存資料管理方式清除 PageZhi 的本機資料，或解除安裝擴充功能。請先另行保存你需要保留的編輯成果或下載檔案；清除擴充功能資料不會自動刪除你已自行儲存至其他位置的檔案。

8. 資訊安全與政策更新

本擴充功能僅為所述功能請求必要的瀏覽器權限。任何軟體或資料處理方式均無法保證絕對安全。若未來加入雲端服務、分析工具，或實質改變資料使用方式，我們將更新本政策及相關商店揭露資訊。
