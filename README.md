# PageZhi｜頁織

**網頁截圖與圖片編輯，一站完成。**

PageZhi 是一款免費的 Chrome 擴充功能，協助使用者快速擷取網頁、編輯圖片，並將成果儲存或分享。

由 **YIZEN Studio｜浥榛工作室** 維護。

## 主要功能

- **完整網頁截圖**：擷取超出螢幕可視範圍的長網頁。
- **區域截圖**：自由選擇需要保留的畫面。
- **圖片標註**：加入文字、箭頭及幾何形狀。
- **馬賽克處理**：遮蔽圖片中的敏感內容。
- **裁切與複製**：整理截圖並複製至剪貼簿。
- **PNG／PDF 匯出**：將編輯成果儲存為圖片或 PDF。
- **PDF 匯入**：將 PDF 文件匯入編輯流程。
