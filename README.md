# PageZhi｜頁織

**網頁截圖與圖片編輯，一站完成。**

PageZhi 是一款免費、輕量且直覺的 Chrome 擴充功能，協助使用者快速擷取網頁、編輯圖片，以及將成果匯出為 PNG 或 PDF。

由 **YIZEN Studio｜浥榛工作室** 維護。

## 主要功能

### 📸 網頁截圖
- **完整網頁截圖**：自動捲動並擷取超出螢幕可視範圍的長網頁。
- **區域截圖**：自由框選需要保留的畫面。
- **快速複製**：將指定範圍直接複製到系統剪貼簿。

### ✏️ 圖片編輯與標註
- **文字標註**：在圖片中加入文字說明。
- **形狀與線條**：支援矩形、圓形、箭頭及直線。
- **螢光筆**：自由標記重點，可選取、移動及調整筆跡大小。
- **馬賽克**：遮蔽圖片中的敏感內容。
- **圖片裁切**：快速保留需要的範圍。
- **復原與重做**：方便調整編輯操作。

### 📄 PDF 與圖片匯出
- 支援 PDF 文件匯入及多頁合成長圖。
- 將編輯成果下載為 PNG 圖片。
- 將編輯成果匯出為 PDF 文件。

### 🗑️ 本機暫存管理（2.2.4）
- 在擴充功能選單查看暫存截圖數量。
- 手動清除本機暫存截圖。
- 清除前提供確認提示，避免誤刪。
- 不會刪除已下載的 PNG、PDF 或其他位置的檔案。

## 2.2.4 更新重點

- **長圖拼接改善**：修正部分網頁接縫留白及縮放比例造成的誤差。
- **響應式工具列**：重新整理工具選擇與設定區域，改善窄視窗操作體驗。
- **螢光筆操作優化**：使用輕量端點提示及實際筆跡命中判斷，減少大型選取框干擾。
- **手動清除暫存**：新增暫存數量顯示、清除確認與操作保護。

正式版本更新紀錄將於發布後公布在 [GitHub Releases](https://github.com/yizen-studio/pagezhi/releases)。

## 隱私權與資料管理

PageZhi 的截圖及圖片編輯主要在使用者的瀏覽器本機進行。

為支援長網頁截圖與編輯器，本擴充功能可能於瀏覽器本機暫存截圖工作資料。

自 2.2.4 起，使用者可以透過擴充功能選單手動清除暫存截圖。詳細資料處理方式、保留情況與注意事項，請參閱隱私權政策。
