# PageZhi｜頁織

**網頁截圖與圖片編輯，一站完成。**

PageZhi 是一款免費、輕量且直覺的 Chrome 擴充功能，協助使用者快速擷取網頁、編輯圖片，以及將成果匯出為 PNG 或 PDF。

由 **YIZEN Studio｜浥榛工作室** 維護。

## 主要功能

### 📸 網頁截圖

- **完整網頁截圖**：自動捲動並擷取超出螢幕可視範圍的長網頁。
- **區域擷取**：自由框選需要保留的畫面，並進入圖片編輯器。
- **區域快速複製**：框選指定範圍後，直接複製至剪貼簿。

### ✏️ 圖片編輯與標註

- **文字標註**：在圖片中加入文字說明。
- **形狀與線條**：支援矩形、圓形、箭頭及直線。
- **螢光筆**：自由標記重點，可選取、移動及調整筆跡大小。
- **馬賽克**：遮蔽圖片中的敏感內容。
- **圖片裁切**：快速保留需要的範圍。
- **復原與重做**：方便調整編輯操作。

### 📄 PDF 與圖片匯出

- 支援 PDF 文件匯入及多頁合成長圖。
- 將圖片編輯成果下載為 PNG。
- 將圖片編輯成果匯出為 PDF。

### 🗑️ 本機暫存管理

- 在擴充功能選單查看本機暫存截圖數量。
- 手動清除暫存截圖。
- 清除前提供確認提示，降低誤刪風險。
- 不會刪除已下載至其他位置的 PNG 或 PDF 檔案。

## 下一版本規劃：2.2.5

2.2.5 將以截圖效率、編輯器操作及圖片預覽體驗為主要改善方向。

### 快速擷取

- **擷取目前畫面**：一鍵擷取目前可見的網頁內容。
- **擷取並編輯**：將目前畫面或框選區域送入編輯器。
- **擷取並複製**：將目前畫面或框選區域直接複製到剪貼簿。

### 操作介面改善

- 重新設計單頁式擴充功能選單。
- 整合 PNG／PDF 下載選項。
- 統一編輯器及圖片預覽頁的圖示與操作文字。

### 新分頁圖片預覽

- 可分別開啟原始截圖及目前編輯成果。
- 提供符合寬度、原始大小、放大及縮小。
- 支援下載 PNG 及複製圖片。
- 已成功載入的預覽可以在關閉編輯器後繼續使用。

> 以上為開發中的版本規劃，實際功能與發布時程以最終測試及 Chrome Web Store 公開版本為準。

## 隱私權與資料管理

PageZhi 的截圖與圖片編輯主要在使用者的瀏覽器本機進行。

為支援完整網頁截圖及編輯器，本擴充功能可能在瀏覽器本機暫存截圖工作資料。

自 2.2.4 起，使用者可以透過擴充功能選單手動清除暫存截圖。

詳細資料處理方式、保留情況與注意事項，請參閱：

**[PageZhi 隱私權政策](https://yizen-studio.github.io/pagezhi/)**
